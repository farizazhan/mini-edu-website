Что такое CI/CD?

CI — автоматическая проверка кода при каждом изменении. CD — автоматическая публикация проверенного кода на сайт.

Что использовано в проекте

  • GitHub — хранение кода
  • GitHub Actions — автоматизация
  • HTMLHint — проверка HTML
  • GitHub Pages — бесплатный хостинг
