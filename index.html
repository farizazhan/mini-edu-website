Что такое CI/CD?

CI (Continuous Integration) — автоматическая проверка кода при каждом изменении. CD (Continuous Delivery/Deployment) — автоматическая доставка проверенного кода на сайт.

Что использовано в проекте

  • Git и GitHub — хранение кода
  • GitHub Actions — автоматизация
  • HTMLHint — проверка качества HTML
  • GitHub Pages — бесплатный хостинг
